Web tools

No. 04 · Web tool · Open source

Stamp Duty Calculator

Works out Malaysian stamp duty under the Stamp Act 1949 — property transfers with every relief, loans and financing, shares, tenancies and more — plus late-stamping penalties and solicitors' scale fees, with the working shown so you can check it.

Try it View on GitHub

THE PROBLEM

Clients ask "how much stamp duty?" before every transfer and loan. The tiered rates are simple to apply but easy to slip on under time pressure.

COVERS

Property transfers Loans & financing Share transfers Tenancies Service & employment Late penalty (s 47A) Legal fees (SRO 2023)

AI

No. 05 · AI · Final-year CS project

LexAI

An offline client-intake assistant for Malaysian employment lawyers. Clients can speak, type or upload documents; LexAI answers from the Employment Act 1955 and Industrial Relations Act 1967 — and cites only the provisions it actually retrieved.

View on GitHub

DESIGN CHOICES

  • Runs locally — client data never leaves the machine
  • Section-aware chunking keeps each statutory provision intact
  • Prompt constrained to cite retrieved provisions only, to curb hallucination
